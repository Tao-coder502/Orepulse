# OrePulse AI

## Interactive Agentic Mining Learning Laboratory

OrePulse AI is an educational mining simulation for the Kansanshi Mining PLC AI Hackathon 2026. It demonstrates agentic AI, mining process education, multi‑agent collaboration, deterministic simulation, safety guardrails, and human oversight.

### Two Runtimes
- **TypeScript Application Runtime** – React + Vite front‑end, Fastify back‑end, Zod for validation.
- **Python Agent Runtime** – Google ADK 2.0 for genuine agentic graph workflows, specialist agents, and structured explanations.
